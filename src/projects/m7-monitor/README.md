# M7 实时监控案例动效

motion.js / motion.css 使用项目本地 GSAP 与 ScrollTrigger。
- 首屏图片收拢入场、标题与标签错峰显现。
- 首屏鼠标轻微视差、滚动离场与阅读进度条。
- 首屏图片入场及滚动仅缩放，始终保持不透明；页面和首屏使用黑色兜底背景，避免刷新或滚动露出蓝底。
- 11 个案例章节独立显现及末段淡出，保留原始 Figma 1920 画布缩放。
- 可视区域内关键数据递增展示。
- 评审页的最终决策正文、研发侧标题及正文参考 React Bits ScrollReveal，按中文词语随滚动从 10% 透明度、4px 模糊、3° 倾斜逐步显现；支持反向滚动和减少动态效果设置。
- 返回作品列表时与原有曲面转场配合。
- gsap.matchMedia 负责断点和减少动态效果切换，动画层不会接管滚轮或改变章节高度。

npm run build 生成 M7-MONITOR.html 和 dist/M7-MONITOR.html。
