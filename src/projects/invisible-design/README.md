# 无感设计分享视频页

页面：根目录及 dist/INVISIBLE-DESIGN.html，由 build.mjs 读取本目录源码生成。

参考：https://iconoclast.tv/uk/ 的 Player/VideoCarousel 样式采用视口高度、宽高 100% 和 object-fit:cover；本站使用本地演示视频、原有作品页页头及 68px 白球样式。

视频静音自动循环播放，鼠标白球随指针移动并切换暂停/播放图标；支持点击、键盘、触屏及声音开关。导航或页面隐藏时暂停，关闭导航时仅恢复之前正在播放的视频。从作品列表曲面转场进入后自动播放。

## 飞书阅读区

`document.html`、`document.css`、`document.js` 在全屏视频下接入用户指定的知识库链接。保留黑底的左右分栏项目导语，阅读窗口高度约为视口的 86%，配备展开／收起、飞书原文和重新加载。正文由飞书页面直接展示，网站不提取、改写或代理正文。导语只依据已核实的文档标题和项目概述概括分享主题。

设计：DESIGN_VARIANCE 5、MOTION_INTENSITY 3、VISUAL_DENSITY 3，沿用本站黑色背景、灰色大标题、3.2vw 页边距和手机 22px 页边距；原始文档白底保留在阅读窗口内部。使用现有本地 GSAP，无新增第三方依赖。

iframe 在接近视口时才加载。它始终处于同一个 DOM 位置，展开使用原生 Popover 顶层（不支持时使用 fixed 布局），避免 reparent 导致文档重新加载。展开时锁定页面背景、限制焦点范围；收起恢复页面位置与工具栏焦点。文档内部保留自己的滚动、目录和鼠标。跨域 iframe 内的键盘事件不会传到本站，所以收起按钮始终可见；Escape 适用于本站工具栏获得焦点时。

iframe 的 load 事件不代表正文权限或渲染已经成功。网站不声称能检测飞书内部状态；保留空白／登录提示及原文入口，12 秒无响应时提示连接较慢并释放加载遮罩，重新加载可手动重试。正常展开、收起不修改 src。飞书资源的网络连接、分享权限和登录状态决定实际内容可用性。

本页视频通过 `data-pause-offscreen` 启用离屏暂停，回到首屏时仅恢复之前正在播放的视频。DYSLEXIA 保持自己的既有行为。

验证：`node qa/verify-invisible-document.cjs` 使用受控远程响应验证生命周期与异常恢复；真实飞书访问单独进行浏览器检查。2026-11-11 的实际测试可读取并嵌入正文，没有 frame-ancestors / X-Frame-Options 阻止；部分 `lf-package-cn.feishucdn.com` 资源出现 TLS 连接中断，可能影响飞书样式和媒体，属于远程网络链路限制。
